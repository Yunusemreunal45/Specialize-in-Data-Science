# Data Science Specialization – Project Portfolio

This repository contains a comprehensive collection of **21 data science projects** completed as part of the **Data Science Specialization** assignment.

The projects are selected from the following resources and implemented using my own code and methodology, while also comparing results with the provided reference solutions:
